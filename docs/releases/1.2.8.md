# The Story Nexus 1.2.8

GitHub release title: `The Story Nexus 1.2.8`

Recommended tag: `1.2.8`

## GitHub Release Body

The Story Nexus 1.2.8 makes app updates easier. Install this version manually once, and future releases can be checked and installed from inside the app.

### What's New

- Added in-app update checking for desktop releases.
- Added a quiet startup update check that only appears when a new version is available.
- Added a manual **Check for Updates** button in the Backup & Delete panel.
- Added an install prompt when a new version is available.

### Upgrade Notes

- Existing users need to install this release manually.
- After installing 1.2.8, future releases can be installed from inside The Story Nexus.
- Windows may still show a SmartScreen warning for new or unsigned builds.

### Download

Download and run:

```text
thestorynexus_1.2.8_x64_en-US.msi
```

You do not need to download any other files.
