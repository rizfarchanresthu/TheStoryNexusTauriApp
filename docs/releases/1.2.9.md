# The Story Nexus 1.2.9

GitHub release title: `The Story Nexus 1.2.9`

Recommended tag: `1.2.9`

## GitHub Release Body

The Story Nexus 1.2.9 adds better worldbuilding support in Brainstorm and Lorebook, making it easier to turn a premise into reusable story context.

### What's New

- Added new lorebook categories for **Magic System** and **World Rule** entries.
- Added a **World Seed Builder** Brainstorm template for generating starter-world lorebook JSON from a premise.
- Added a review step before importing generated lorebook entries from Brainstorm.
- Improved Brainstorm template insertion so long inserted templates resize and scroll correctly.
- Added prompt variables for magic systems and world rules so prompts can use those lorebook entries directly.

### Upgrade Notes

- Existing stories continue to work normally.
- To add the new World Seed Builder to your Brainstorm Insert menu, open **Insert... -> Export / Import... -> Restore Default Templates**.
- Windows may still show a SmartScreen warning for new or unsigned builds.

### Download

```text
thestorynexus_1.2.9_x64_en-US.msi
```
