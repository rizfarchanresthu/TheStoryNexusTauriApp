# The Story Nexus 1.2.8

GitHub release title: `The Story Nexus 1.2.8`

Recommended tag: `1.2.8`

## GitHub Release Body

The Story Nexus 1.2.8 adds the first updater-enabled desktop release. This is a bridge release: install it manually once, and future releases can be discovered from inside the app.

### What's New

- Added Tauri auto-update support for Windows MSI releases.
- Added a startup update check that stays quiet unless an update is available.
- Added manual update controls in the Backup & Delete maintenance panel.
- Added updater signing and release helper commands for manual GitHub Releases.
- Added signed updater artifact generation alongside the MSI build.

### Upgrade Notes

- Existing users need to install this release manually from GitHub Releases.
- After installing 1.2.8, future updater-enabled releases can be installed from inside the app.
- Windows may still show SmartScreen warnings for unsigned/new builds. The updater signature verifies Tauri update integrity, but it is separate from Windows code signing.

### Release Assets

Upload these files to the GitHub release:

- `thestorynexus_1.2.8_x64_en-US.msi`
- `thestorynexus_1.2.8_x64_en-US.msi.sig`
- `latest.json`

`latest.json` must be uploaded with the exact filename `latest.json` so installed apps can check:

```text
https://github.com/vijayk1989/TheStoryNexusTauriApp/releases/latest/download/latest.json
```

## Manual Release Checklist

1. Confirm version is `1.2.8` in:
   - `package.json`
   - `package-lock.json`
   - `src-tauri/Cargo.toml`
   - `src-tauri/tauri.conf.json`
   - `README.md`

2. Build the signed MSI and updater signature:

```powershell
make -f Makefile updater-build
```

3. Confirm release artifacts:

```powershell
make -f Makefile updater-files
```

Expected files:

```text
src-tauri\target\release\bundle\msi\thestorynexus_1.2.8_x64_en-US.msi
src-tauri\target\release\bundle\msi\thestorynexus_1.2.8_x64_en-US.msi.sig
```

4. Create `latest.json` after the MSI has its final GitHub Release download URL:

```powershell
make -f Makefile updater-json MSI_URL=https://github.com/vijayk1989/TheStoryNexusTauriApp/releases/download/1.2.8/thestorynexus_1.2.8_x64_en-US.msi SIG_FILE=src-tauri/target/release/bundle/msi/thestorynexus_1.2.8_x64_en-US.msi.sig RELEASE_NOTES="The Story Nexus 1.2.8"
```

5. Upload `dist\updater\latest.json` to the GitHub release as `latest.json`.

6. Create tag `1.2.8` from the verified release commit.

7. Publish the GitHub release using the title and release body above.

## Verification Before Publishing

Run:

```powershell
npm run build
npm run test:unit
make -f Makefile updater-build
```

Expected warnings:

- Rollup may warn about Lexical `/*#__PURE__*/` annotations.
- Vite may warn that the main chunk is larger than 500 kB.
